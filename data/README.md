# data/salary-table.json の配置方法

公式の俸給表データが手に入ったら、このディレクトリに `salary-table.json` という名前で配置してください。
アプリ起動時（`js/app.js`）に自動でこのファイルを読み込み、`js/data.js` 内の参考値（推定値）の代わりに使用します。

読み込みには `fetch` を使うため、簡易HTTPサーバー経由（例: `python3 -m http.server`）でアクセスしている必要があります。
`file://` で直接開いた場合は読み込みに失敗し、参考値にフォールバックします。

## フォーマット

```json
{
  "table": "行政職俸給表(一)",
  "effectiveDate": "2025-04-01",
  "grades": {
    "1": [145600, 146700, 147800, 148900],
    "2": [177600, 178800, 180000],
    "10": [411900, 415200]
  }
}
```

- `grades` の各キーは職務の級（"1"〜"10"など、文字列）。
- 値は号俸1番目から順に並べた俸給月額（円）の配列。号俸数は級ごとに異なって構いません。
- `table` / `effectiveDate` は画面上の注記表示に使われます（省略可）。

CSV しかない場合は、以下のような3列（級, 号俸, 俸給月額）のCSVを渡していただければ、
このJSON形式に変換するスクリプトを追加で用意します。

```csv
grade,step,amount
1,1,145600
1,2,146700
2,1,177600
```
