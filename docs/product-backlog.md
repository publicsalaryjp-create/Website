# プロダクトバックログ

## これは何か

「いつかやりたいこと・直したいこと」を全部書き出して、優先順位をつけたリストです。
思いついたことをいきなり実装するのではなく、まずここに書いてから着手することで、
「今何をやっていて、何が残っているか」が誰にでも分かるようにします。

## 使い方

1. やりたいことを思いついたら、下の表の一番下に新しい行を追加する（IDは連番）。
2. 優先度（高・中・低）をつける。分からなければ「中」でOK、あとで見直せます。
3. 着手するときは `docs/definition-of-done.md` の「Definition of Ready」を確認する。
4. 着手したらステータスを「対応中」に、完了したら「完了」に変える。
5. スプリントを始めるときは、この表から優先度の高い項目を選んで
   `docs/sprints/` にスプリント記録を作る（`docs/sprint-template.md` 参照）。

## 優先度の目安

| 優先度 | 意味 |
|---|---|
| 高 | 給与計算の正確性に直結する／制度上重要 |
| 中 | 使い勝手や分かりやすさの向上 |
| 低 | あれば嬉しいが急がない |
