# 要件定義書：国家公務員給与計算シミュレーター

> 本書は実装完了後に作成した要件定義書です。既存実装（2026年7月時点）の仕様を
> 正として記述し、今後の変更・拡張の基準として用います。

## 1. 概要

### 1.1 目的

国家公務員（一般職）の給与制度への理解を助けるため、俸給表・各種手当・賞与・
超過勤務手当から月給および年収の**概算**を算出するWebサイトを提供する。

### 1.2 想定利用者

- 国家公務員志望者・就職活動中の学生（給与水準の把握）
- 現職の国家公務員（自身の給与のシミュレーション）
- 給与制度に関心のある一般ユーザー

### 1.3 非対象

- 実際の給与明細の再現や、税務・労務上の正式な計算根拠としての利用
- 地方公務員・独立行政法人職員等、国家公務員（一般職）以外の給与計算

## 2. システム方式

| 項目 | 内容 |
|---|---|
| 種別 | 静的Webサイト（クライアントサイドのみ、サーバーサイド処理なし） |
| 実装技術 | HTML / CSS / バニラJavaScript（ビルド不要、フレームワーク不使用） |
| データ配信 | `data/salary-tables.json` を `fetch` で読み込み（`file://` 実行時は組み込みの参考値にフォールバック） |
| 想定ホスティング | 静的ホスティング（GitHub Pages等）。ローカル確認は簡易HTTPサーバー経由 |
| 対応ブラウザ | `fetch` / `Intl.NumberFormat` 等のモダンAPIが使える最近のブラウザ |
| レスポンシブ対応 | あり（760px以下でフォーム・結果を縦積みに切り替え） |
| コード構成 | `js/data.js`（データ）・`js/calculator.js`（DOM非依存の計算ロジック）・`js/form-controls.js`（フォーム制御・表示ロジック）・`js/app.js`（DOM配線）に分割 |

## 3. 機能要件

### 3.1 俸給表選択・俸給月額の算出

- 俸給表（俸給の種類）をプルダウンで選択できる。`data/salary-tables.json` 自体は以下19表を
  保持している：行政職俸給表(一)、専門行政職、税務職、公安職俸給表(一)(二)、海事職俸給表(一)(二)、
  教育職俸給表(一)(二)、研究職、医療職俸給表(一)(二)(三)、福祉職、専門スタッフ職、
  指定職、任期付研究員俸給表（第一号・第二号）、特定任期付職員俸給表。
  行政職俸給表(二)はユーザー指示により対象外としている。
  選択肢（プルダウン）はユーザー指示により、一旦「行政職俸給表(一)」「指定職俸給表」の2表に
  絞っている（`js/data.js` の `VISIBLE_TABLE_KEYS`）。他の表は将来的に解禁する想定でデータは
  そのまま残している。
- 俸給表には「級構成（`graded`）」と「級のないフラット構成（`flat`）」の2種類があり、
  `flat`型（指定職・任期付研究員等）を選んだ場合は「職務の級」入力欄を自動的に非表示にする。
- `graded`型は「職務の級」→「号俸」の順にプルダウンを連動させ、選択した級・号俸に対応する
  俸給月額（円）を取得する。号俸の選択肢数は俸給表・級ごとに異なる実データに追従する。
- 俸給の特別調整額は行政職俸給表(一)の対象級・区分にのみ適用する。指定職職員には支給せず、
  `calculateSalary()`へ値が渡された場合も常に0円として扱う。

### 3.2 地域手当

- 勤務地の級地区分（1級地20%／2級地16%／3級地12%／4級地8%／5級地4%／非支給地0%）を
  プルダウンで選択する。
- 地域手当額 =（俸給月額＋俸給の特別調整額＋扶養手当額）× 選択した率
  （小数点以下切り捨て）。
- 級地区分プルダウンの上に「地域名から選ぶ（任意）」プルダウンを設置し、代表的な
  市区町村名（`REGIONAL_ALLOWANCE_REGION_EXAMPLES`、網羅的ではない参考用リスト、
  出典の確度: 中）を選ぶと、対応する級地区分プルダウンの値へ自動的に反映する。
  掲載のない地域は、従来どおり級地区分プルダウンから直接選択する。級地区分プルダウンを
  直接変更した場合は、地域名選択は（対応する地域が一致しない限り）解除される。
- 級地区分プルダウンの下に、級地区分ごとの支給割合を一覧できる折りたたみ表（`<details>`）を設置。
  既定では閉じており、クリックで開閉する。データは`REGIONAL_ALLOWANCE_RATES`
  （プルダウンと共通）から描画するため、率の追加・変更をした場合は自動的に反映される。

### 3.3 扶養手当

- 令和8年4月現在の額のみを対象とする（年度別の切替はしない）。配偶者に係る手当は
  令和8年度時点で廃止済みのため、本ツールでは扱わない。
- 子は「15歳以下」と「16歳以上22歳以下」で額が異なり、後者には加算がある
  （出典: 人事院「国家公務員の諸手当の概要」令和8年4月現在）。
  - 子（15歳以下）: 13,000円
  - 子（16歳以上22歳以下）: 18,000円（基本額13,000円+加算5,000円）
  - 父母等: 6,500円（年度別の正式額は未確認のため一律値）
- 入力: 扶養する子の数（15歳以下）、扶養する子の数（16歳以上22歳以下）、扶養する父母等の数。
  各項目は数値の直接入力ではなく、「−」「＋」ボタンによるボタン選択式（0未満にはならない）。
- 扶養手当額 = 子（15歳以下）の手当額×人数 + 子（16歳以上22歳以下）の手当額×人数 + 父母等の手当額×人数。

### 3.4 住居手当

- まず「支給の有無」（支給なし＝持ち家など／支給あり＝借家・借間など）を選択する
  （既定は支給なし＝0円）。持家世帯向けの住居手当は制度上廃止済みのため、「支給なし」を
  持ち家の代表的なケースとして扱う。
- 「支給あり」を選ぶと家賃（月額）の入力欄が表示され、`calcHousingAllowance(rent)`で
  住居手当額を自動計算する。家賃16,000円超〜27,000円以下は「家賃−16,000円」、
  27,000円超は「11,000円＋（家賃−27,000円）の半額」（上限28,000円）とし、
  **算出した支給額の100円未満を切り捨てる**。
  入力中の家賃に応じた金額をヒントテキストにも表示する。
- 「支給なし」を選ぶと金額入力欄は非表示になり、直前に入力していた家賃額があっても
  `housingAllowance` は常に0円として扱われる（フィールドに値が残っていても計算には
  使われない）。
- 通勤手当は本ツールの対象外（非対応）。

### 3.5 本府省業務調整手当（本省手当）

- 本府省（霞が関）勤務の職員に支給される手当（出典: 給与法10条の3、人事院規則9-123）。
  利用者は「支給の有無」（支給なし／支給あり）のみを選択し、金額は選択している職務の級
  から自動計算する（`getHonshoAllowanceAmount(grade)`）。7級以上は一律「7級以上」の額を
  適用し、flat型俸給表の選択時など級が取得できない場合は0円となる。
- 「支給あり」を選ぶと、選択中の級に対応する参考額をヒントテキストに表示する
  （例:「4級の参考額: ￥24,100」）。算出値はそのまま `honshoAllowance` として
  月額支給額に算入されるが、超過勤務手当の算定基礎（時間単価）にも期末・勤勉手当の
  算定基礎額にも含めない簡略化とする。
- 参考額（1級9,200円〜7級以上51,800円）はユーザー提供の令和8年度人事院公表資料
  （行政職俸給表(一)の級別月額表、画像）に基づく値（出典の確度: 高）で、令和8年度
  人事院勧告による増額改定を反映済み。行政職俸給表(一)以外の俸給表を選んでいる場合、
  本来は「相当する職務の級」への読み替えが必要な場合があるが、本ツールでは選択中の
  級番号をそのまま適用する簡略化としている（PBI-035参照）。金額は自動計算するため、
  級別の参考額を一覧できる別表示（折りたたみ表）は設けていない。

### 3.6 期末・勤勉手当（賞与）

- 期末手当と勤勉手当を分けて計算し、それぞれ6月期・12月期の額を表示する
  （出典: 人事院「国家公務員の諸手当の概要」令和8年度）。
- 共通算定基礎額（`bonusBase`） = 俸給月額 + 俸給月額に対する地域手当。
- 期末・勤勉手当の役職段階別加算額 = 共通算定基礎額 × 加算割合。指定職および行政職俸給表（一）
  8級以上は20%、6・7級は15%、4・5級は10%、3級は5%。それ以外は0%。この加算額は
  期末・勤勉手当の算定基礎に加える。
- 管理職加算額 = 俸給月額 × 加算割合。指定職は25%。行政職俸給表（一）は
  俸給の特別調整額の区分が一種は25%、二種は15%、三種・四種・五種は0%とし、
  期末・勤勉手当の算定基礎に加える
  （人事院規則九―四〇第四条の四）。
- 期末・勤勉手当の職員区分は、指定職俸給表を除き、俸給の特別調整額が一種・二種の場合のみ
  「特定管理職員」とする。三種以下は俸給の特別調整額を支給するが、賞与計算では「一般職員」の
  期末手当支給月数・成績率を適用する。
- 期末手当の支給月数は `data/allowance-rates.json` で職員区分・支給年月ごとに管理する。
  2026年6月期・12月期は、一般職員1.2625月、特定管理職員1.0625月、指定職職員0.675月。
  年間支給月数は保持せず、各期の値を直接計算に使用する。
- 期末手当（6月期/12月期） =（俸給月額 + 扶養手当 + これらに対する地域手当 +
  役職段階別加算額 + 管理職加算額）× 該当する職員区分・支給期の支給月数
  （成績率は適用しない、小数点以下切り捨て）。
- 勤勉手当（6月期） =（共通算定基礎額 + 役職段階別加算額 + 管理職加算額）× 6月期の成績率（小数点以下切り捨て）。
  勤勉手当（12月期） =（共通算定基礎額 + 役職段階別加算額 + 管理職加算額）× 12月期の成績率（小数点以下切り捨て）。成績率
  （例: 良好「102.25/100」＝1.0225）はそのまま1回あたりの支給割合を表すため、
  期末手当の支給月数を掛ける処理は行わない。
- 職員区分（一般職員／特定管理職員（本府省課長等）／指定職職員）ごとに成績率テーブルが異なる。
  指定職職員には「特に優秀」の区分が存在しない（選択肢から除外）。
- 勤務成績区分（特に優秀／優秀／良好／良好でない）に応じた成績率（令和8年度。テーブル自体は
  6月期・12月期で共通だが、どの区分を適用するかは期ごとにラジオボタンで独立して選択できる）。
  初期値は両期とも「良好」とする:

  | 成績区分 | 一般職員 | 特定管理職員（本府省課長等） | 指定職職員 |
  |---|---|---|---|
  | 特に優秀 | 125.25/100以上318.75/100以下（下限採用） | 149.25/100以上378.75/100以下（下限採用） | 該当なし |
  | 優秀 | 113.75/100以上125.25/100未満（下限採用） | 134.75/100以上149.25/100未満（下限採用） | 115/100以上215/100以下（下限採用） |
  | 良好 | 102.25/100 | 122.25/100 | 101.5/100（事務次官等は107.5/100） |
  | 良好でない | 93.75/100以下 | 112.75/100以下 | 93/100以下 |

  成績率に幅がある区分（特に優秀・優秀）は、ユーザー指示により下限値を採用している。
- 賞与年間合計 = 6月期（期末+勤勉） + 12月期（期末+勤勉）。
- 成績率逆算ツールでは、行政職俸給表（一）の俸給の特別調整額が一種・二種の場合は
  「特定管理職員」、三種以下の場合は「一般職員」を選択する。管理職加算額と役職段階別加算額は
  期末・勤勉手当の両方の算定基礎に共通して含まれるため、期末手当から推定した勤勉手当算定基礎額に
  引き継がれ、逆算式で個別に加減算しない。
- 成績率逆算ツールの入力内容はブラウザの `localStorage` に保存し、再読み込み・次回アクセス時に
  復元する。入力内容はサーバーへ送信しない。
- 成績率逆算ツールの地域手当は、最初にラジオボタンで「地域から選ぶ」または
  「支給割合を直接選ぶ」を選択し、選択した方法の入力欄だけを表示する。

### 3.7 超過勤務手当（残業代）

- 時間単価 = (俸給月額 + 俸給月額に対する地域手当) × 12か月 ÷ 年間所定勤務時間。
  年間所定勤務時間 = 週38時間45分 × 52週 = 2,015時間。扶養手当とそれに対応する地域手当、
  住居手当、本省手当は算定基礎に含めない。
- 入力: 平日時間外勤務時間（深夜を除く月間合計）、うち深夜(22時〜翌5時)の時間外勤務時間、
  休日勤務時間（深夜を除く月間合計）、うち深夜の休日勤務時間。いずれも1時間単位
  （入力欄は`step="1"`。小数で入力された場合も読み取り時に四捨五入で整数時間に丸める）。
- 割増率:

  | 区分 | 月60時間以下 | 月60時間超 |
  |---|---|---|
  | 平日時間外（22時まで） | 125% | 150% |
  | 平日時間外・深夜（22時〜翌5時） | 150% | 175% |
  | 休日勤務（22時まで） | 135% | （60時間判定の対象外、常に135%） |
  | 休日勤務・深夜 | 160% | （60時間判定の対象外、常に160%） |

- 月60時間の判定対象は「休日勤務を除く時間外勤務時間（深夜を含む）」の合計。60時間を
  超えた分は、平日の通常時間から優先的に充当し、それでも不足する場合は深夜時間に充当する
  （実際の勤務順序までは特定できないための簡便な割当てであることを画面上に明記する）。
- 手当額 = 区分（平日通常／平日超過／平日深夜／平日深夜超過／休日／休日深夜）ごとに
  「時間単価 × 割増率」を先に四捨五入し（時間単価そのものは四捨五入しない）、その
  四捨五入後の単価に時間数を掛けたうえで、6区分すべてを合算する（例:
  `round(単価×1.25)×平日通常時間 + round(単価×1.5)×平日超過時間 + ...`）。
  最終的な合計額を一括で端数処理するのではなく、区分ごとの「単価×割増率」の時点で
  端数処理する。
- 60時間を超えている場合、結果画面にその旨の注記を表示する。
- 「職員区分（現在）」（一般職員／特定管理職員／指定職職員、3.6節の職員区分と同じ選択肢を
  流用）を設け、特定管理職員・指定職職員を選んだ場合は超過勤務手当の支給対象外として
  時間外勤務時間をすべて0として扱い、超過勤務手当を0円で計算する。この場合、時間入力欄
  一式は非表示にし、その旨の注記を表示する（ユーザー指示: 管理職は超勤手当の対象外）。
  6月期・12月期の職員区分（3.6節）とは別に、期に依存しない単一の選択肢として持つ。

### 3.8 計算結果表示

以下を一覧表示する（すべて円単位、`Intl.NumberFormat` によるフォーマット）。

1. 俸給月額
2. 地域手当
3. 扶養手当
4. 住居手当
5. 本省手当
6. 月額支給額 合計（残業代除く）＝ 1〜5の合計
7. 時間外勤務の時間単価
8. 超過勤務手当
9. 月額支給額 合計（残業代込み）＝ 6 + 8
10. 期末手当（6月期）／勤勉手当（6月期）
11. 期末手当（12月期）／勤勉手当（12月期）
12. 賞与（年間合計）＝ 10 + 11
13. 年収 概算 ＝ 9 × 12 + 12（毎月同じ超過勤務が続くと仮定した概算）

入力変更時はページ遷移・送信なしにリアルタイムで再計算・再描画する。

### 3.9 データ読み込みと表示

- 起動時に `data/salary-tables.json` を非同期で読み込み、成功すれば実データ（19表）を、
  失敗すれば行政職俸給表(一)相当の参考値にフォールバックする。
- 読み込み結果（実データか参考値か、データの適用時点）を画面上部の注記に表示する。

### 3.10 俸給表バージョン切替

- 画面上部に「俸給表のバージョン」選択欄を設け、`data/vintages.json` に列挙された
  バージョン（例: 現行／人事院勧告後）を切り替えられる。
- 各バージョンは `{ key, label, file, effectiveDate, available }` を持ち、`file` が
  `null`／`available: false` のバージョンは選択肢を無効化し、選ぼうとしても現行データに
  留まる（データ未登録の旨を注記表示）。
- バージョンを切り替えると、俸給表選択・級・号俸のプルダウンを再取得したデータに合わせて
  リセットする。
- 2026年7月時点では `current`（現行、2026-04-01施行）のみデータが登録されており、
  `post_recommendation`（人事院勧告後）は未登録（PBI-013として保留中）。

### 3.11 入力内容の保存・復元

- フォーム（`#calc-form`）内のid付きinput/selectすべての値を、変更のたびに
  `localStorage`へキー（`salary-calculator:index`）で自動保存する。サーバーへは送信しない。
- 次回アクセス時、ページ読み込み時に保存済みの値があれば自動的に復元し、続きから
  計算できるようにする。俸給表・級・号俸・成績区分など、他の項目の
  選択肢に影響する項目は、選択肢を再構成した後に復元する（例: 俸給表を復元してから
  級の選択肢を作り、その中に保存済みの級があれば選択する）。select要素は、保存値が
  現在の選択肢に存在し無効化されていない場合のみ復元する。
- フォーム下部に「保存した入力内容を削除して初期状態に戻す」ボタンを設置し、
  押すと保存データを削除してページを再読み込みする（既定値に戻る）。
- 画面上部の注意書きに、入力内容がこの端末のブラウザ内に保存され、サーバーには
  送信されない旨を明記する。
- `localStorage`が使えない環境（プライベートブラウジング等）では、保存・復元を
  静かに諦め、通常どおり既定値で動作する（エラーにはしない）。

## 4. 非機能要件

- **正確性の限界の明示**: 画面上部に常時、概算シミュレーターであること・控除前の額面
  ベースであることを明記する。
- **オフライン耐性**: `data/salary-tables.json` が取得できない環境でも参考値でアプリが
  機能し続けること（クラッシュしない）。
- **保守性**: 俸給表データは `scripts/extract-salary-tables.py` により元データ（xlsx）
  から再生成可能とする。
- **アクセシビリティ**: 結果パネルに `aria-live="polite"` を付与し、再計算結果が
  スクリーンリーダーに通知されるようにする。
- **パフォーマンス**: ビルドプロセスを持たず、静的ファイルの配信のみで完結すること。
- **テスト容易性**: 計算ロジック（`js/data.js` / `js/calculator.js`）はDOMに依存しない
  純粋関数として実装し、Node上でユニットテストできるようにする。

## 5. データ仕様

### 5.1 `data/salary-tables.json`

```json
{
  "source": "データの出典説明",
  "note": "適用時点・注意事項",
  "effectiveDate": "YYYY-MM-DD",
  "order": ["administrative_1", "..."],
  "tables": {
    "<table_key>": {
      "label": "画面表示用ラベル",
      "type": "graded | flat",
      "grades": { "<級>": [号俸1の俸給月額, 号俸2の俸給月額, ...] },
      "steps": [号俸1の俸給月額, ...]
    }
  }
}
```

- `type: "graded"` は `grades` を、`type: "flat"` は `steps` を持つ。
- 出典: ユーザー提供の公式俸給表データ（一般職の職員の給与に関する法律 別表に基づく）。
  施行日は令和8年4月1日（2026-04-01）。それ以降に人事院勧告等による改定があった場合は
  最新の公表資料との照合が必要。

### 5.2 `data/vintages.json`

```json
{
  "note": "...",
  "vintages": [
    { "key": "current", "label": "現行（令和8年4月1日施行）", "file": "salary-tables.json",
      "effectiveDate": "2026-04-01", "available": true },
    { "key": "post_recommendation", "label": "人事院勧告反映後（今後実装予定）", "file": null,
      "effectiveDate": null, "available": false }
  ]
}
```

- `file` が `null` または `available: false` のバージョンは選択不可として扱う。

### 5.3 その他の定数データ（`js/data.js` に定義）

- 地域手当率（6区分）
- 扶養手当額（令和8年4月現在。子は15歳以下/16〜22歳の2区分、父母等）
- 本府省業務調整手当（本省手当）の級別参考額（7区分、出典の確度: 高）
- 地域手当の代表的な市区町村名→級地区分の対応例（`REGIONAL_ALLOWANCE_REGION_EXAMPLES`、網羅的ではない、出典の確度: 中）
- 超過勤務手当の割増率（6区分）、年間所定勤務時間
- 勤勉手当の成績率（職員区分3種 × 成績区分4区分、令和8年度）

## 8. 既知の制約・今後の課題

- 勤勉手当の算定基礎額は「俸給+俸給に対する地域手当」を基本とする。期末手当には扶養手当と
  これらに対する地域手当も含める。期末手当には行政職俸給表（一）
  と指定職の役職段階別加算額を反映し、指定職・特定管理職員には管理職加算額も反映する。
  専門スタッフ職調整手当・本省手当等は考慮していない。また、行政職俸給表（一）以外の
  俸給表の役職段階別加算は未対応。
- 超過勤務手当の算定基礎額は「俸給+俸給に対する地域手当」のみを対象とし、扶養手当と
  それに対応する地域手当・広域異動手当・
  研究員調整手当・専門スタッフ職調整手当・本省手当等、対象となりうる他の手当は未実装。
- 本省手当（本府省業務調整手当）は正確な最新額を断定できないため、利用者が実際の支給額を
  直接入力する方式とし、参考として示す級別金額（1級7,200円〜7級以上41,800円）は
  Web検索で確認できた値の集約（出典の確度: 中）。令和8年度人事院勧告による増額改定・
  幹部職員への新規適用（PBI-035）は反映していない。
- 扶養手当のうち父母等の額（6,500円）は正式な出典未確認。子の「16歳以上22歳以下」区分の
  加算額（5,000円）も、人事院公表の「諸手当の概要」PDFに基づく値で法令原文とは未突合。
- 地域手当の「勤務地→級地区分」の市区町村マッピングは、代表的な市区町村のみを掲載した
  参考用リスト（`REGIONAL_ALLOWANCE_REGION_EXAMPLES`、東京都特別区＝1級地以外は
  出典の確度: 中、網羅的ではない）にとどまる。掲載のない地域は利用者が級地区分を
  直接選択する必要がある。人事院規則9-49の原文に基づく全国網羅的なデータ整備は
  未着手（PBI-010）。
- 通勤手当・所得税・住民税・共済組合掛金（社会保険料相当）、単身赴任手当、寒冷地手当等は非対応。
- 年収概算は「毎月同じ超過勤務時間が続く」という仮定に基づく単純な12倍であり、月ごとの
  繁閑は考慮していない。期末・勤勉手当は期間率を考慮していない（通年在籍を前提とした概算）。
- 勤勉手当の成績率テーブル（令和8年度）はユーザー提供の情報に基づくが、原典の法令・
  規則番号は未特定。「特に優秀」「優秀」の階級幅は下限値を採用しており、実際に支給され
  うる上限までは反映していない。
- 「人事院勧告後」の俸給表バージョンはデータ未登録（PBI-013）。ネットワークポリシーにより
  e-Gov法令API・人事院サイトへの直接アクセスがブロックされているため、ユーザーからのデータ
  提供が必要。
